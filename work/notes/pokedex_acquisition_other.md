# Pokédex scripted acquisition audit: remaining sources (2026-10-09)

Reviewed the untouched Chinese v4.0.3 ROM via `gen_docs.Ctx().S` and its GiveMon/GiveEgg/WildBattle records. Conditions were cross-checked with the existing guide audits, whose sources record script conditions and where available CN/EN emulator results. This audit adds no new runtime-test claims. Output: `work/tools/site/acquisition_other.json`.

Scope: all script files outside 169–199 and 733–809, excluding 115 and 842 assigned to the early-Kanto audit. 122 unique species/file/kind/level/form sources; duplicate paths are consolidated, including Latias/Latios and Primo’s duplicate Mareep fallback. All 48 Pal Park standing encounters have their weekday/hour restrictions. Crystal Onix retains form 1.

## Confirmed false sources

- Route 22 Mankey: unused thief quest, no event launches it.
- Sinjoh Regigigas and Arceus: final-story progress blocks the only postgame Azure Flute offer; no normal route returns to the temple. Arceus also requires the variable set by that blocked offer.
- Reversal Cave Lv. 50 Kyogre: unused map 525 with no incoming map/script warp.
- Goldenrod Game Corner Sandshrew: the SoulSilver menu branch is unreachable. Independent code check by wild_trade_sources: CN command 495 pointer at `0x020F793C + 495*4` is `0x02044C6D`; handler writes literal 7 at `0x02044C7E–0x02044C80`. Thus Abra, Ekans, Dratini are the prizes; the path-insensitive variable resolver incorrectly included Sandshrew. Costs are 200/700/2100 coins.
- Rock Tunnel Regice has a duplicate unreachable gift at offset 2403, but the reachable gift at 2262 remains. They share the same one-gift flag, so the consolidated source is valid.

## Review boundaries and unresolved details

- Primo passwords: script conditions, per-species flags and party-space checks confirmed. Existing guide explicitly says not runtime-confirmed; no new claim of an emulator test. The fallback Mareep command at 471 shares flag 345 with the regular Mareep command at 568 and is not an extra Egg.
- File 905 offset 2586 has a runtime species variable with no constant set: the fossil-revival facility. The shared generator already resolves its fossil table separately; it must not be presented as an unknown free gift. Revival is Lv. 20 and requires the corresponding fossil. This audit does not duplicate those generated fossil sources.
- No new starter restriction was found in this scope. Branch requirements are story progress, choices, items, party composition/space, clock/calendar, version or reachability.
- The reviewed `extra_sources.json` has no Regigigas or Arceus `how` override, so none needs removal. Existing form changes/evolution notes are separate from these source conditions.

## Exact-place corrections

Source-specific `place`/`zone` overrides identify the actual room or subarea where the command runs. File 109’s fake-ball script is used only by Victory Road 1F zone124 object8 (script9 at21,40); the other maps sharing file109 have no such event. File841 zone62 contains several disconnected interiors, and Shinx is given by Guesthouse object10/script12 at134,7. File130 zone521 contains separate Dialga/Palkia spaces, at89,30 and25,30 respectively. File24 zone217 Crystal Onix is object0/script4 at50,104 in the hidden chamber (form1). Additional overrides replace misleading vanilla room names for the Mt. Moon altar, Entei dream room, Mew island, Hunyuan Dojo, Mewtwo slope and Shellos house, and clarify the entrances for Dream World/Distortion World.
