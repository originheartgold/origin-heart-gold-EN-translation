# PC wallpaper credits

Original shared Gen IV default wallpapers (16) and HGSS bonus wallpapers (8), downloaded from [PKHeX's wallpaper resources](https://github.com/kwsch/PKHeX/tree/02c9ec108fe3c96735f6c2397eaebc10e29a049f/PKHeX.Drawing.Misc/Resources/img/box) at commit `02c9ec108fe3c96735f6c2397eaebc10e29a049f` on 2026-10-07.

Files `box_wp01dp.png`–`box_wp16dp.png` are the shared default Gen IV artwork; `box_wp17hgss.png`–`box_wp24hgss.png` are HGSS-specific bonus designs. Pokémon game graphics are copyrighted by Nintendo, The Pokémon Company and Game Freak. These third-party graphics are not relicensed under the editor's Apache license. PKHeX source is GPL-3.0; no PKHeX source code is included here.

PNGs are embedded unchanged in `src/ui/pc-wallpapers.ts` so they work offline and with the existing static server. Saved wallpaper IDs 0–15 use the defaults; IDs 32–39 use HGSS bonus designs. The UI preserves the save's wallpaper bytes.
